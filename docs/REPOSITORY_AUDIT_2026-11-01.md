## Lokalna walidacja Bastilla_OS_2

- `npm ci` zakończyło się powodzeniem (317 pakietów), ale runner ma Node `v22.23.4`, podczas gdy dokumentacja wymaga Node 24; npm zgłosił ostrzeżenia zgodności silnika.
- `npm run verify` zakończyło się powodzeniem: 92/92 testy, TypeScript, build web i build serwera. Vite nadal zgłasza duży bundle JavaScript (1,855.03 kB przed gzip).
- `npm audit` zakończyło się kodem 1: cztery pozycje o wysokim severity — `firebase`, `@firebase/firestore`, `@firebase/firestore-compat` i `@grpc/grpc-js`. Raport npm sugeruje zmianę głównej wersji Firebase; zależności pozostawiono bez zmian, bo aktualizacja wymaga osobnego sprawdzenia kompatybilności. Jedno z widocznych advisories dotyczy weryfikacji certyfikatów gRPC: [GHSA-m9gg-hp2v-232j](https://github.com/advisories/GHSA-m9gg-hp2v-232j).
